# engine-service

Service chạy quy trình của ProcessX (Flow System – IPCC 2.0), dựa trên [Flowable](https://github.com/flowable/flowable-engine): thực thi BPMN và DMN (IDM của Flowable tắt — xác thực/phân quyền qua Keycloak).

**Công nghệ:** Java 17, Spring Boot 3.3, Flowable, MariaDB.
